# Dados da disciplina

Esta pasta reúne os conjuntos de dados e a documentação utilizados nas atividades da disciplina Estatística Aplicada — ENBT/JBRJ, edição 2026-II.

Os dados dendrométricos são provenientes do censo do Arboreto do Jardim Botânico do Rio de Janeiro, realizado entre 2021 e 2022.

O arquivo `processed_data.csv` contém o conjunto de dados processado do censo. Para as análises desta edição, será utilizado principalmente o subconjunto de 472 indivíduos de *Roystonea oleracea*.

O dicionário de dados apresenta a descrição das variáveis, suas unidades de medida e orientações para utilização.

**Fonte dos dados:** [Applied Statistics for a Tropical Arboretum](https://github.com/jmalonso55/Applied-Statistics-for-a-Tropical-Arboretum).

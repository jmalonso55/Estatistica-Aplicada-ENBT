# Códigos da disciplina

Esta pasta reúne os roteiros de análise estatística em R utilizados na disciplina **Estatística Aplicada — ENBT/JBRJ**, edição 2026-II.

Os códigos acompanham os conteúdos apresentados em aula e demonstram a aplicação de métodos estatísticos aos dados dendrométricos das palmeiras-imperiais (*Roystonea oleracea*) do Arboreto do JBRJ.

Os materiais são disponibilizados em dois formatos:

- **R Markdown (.Rmd):** arquivos com códigos, comentários e interpretações, que podem ser executados e modificados no RStudio.
- **HTML (.html):** versões renderizadas dos roteiros, permitindo consultar os procedimentos e resultados sem executar os códigos.

Os arquivos de dados necessários às análises estão disponíveis na pasta [`dados`](../dados/).

Os roteiros poderão ser atualizados ao longo da disciplina, acompanhando o desenvolvimento das atividades práticas.

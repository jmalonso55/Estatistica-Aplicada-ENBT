Temática da edição 2026-II

A disciplina utiliza dados dendrométricos do censo de 2021–2022 do Arboreto do JBRJ, com foco em 472 indivíduos de Roystonea oleracea, distribuídos em 52 canteiros. As atividades abordam a estrutura das palmeiras-imperiais, suas diferenças entre locais de plantio e alternativas para o monitoramento da população.

Como utilizar os materiais

  1. Consulte as apresentações correspondentes aos conteúdos das aulas.
  2. Execute e adapte os roteiros em R Markdown no RStudio.
  3. Utilize os dados e o dicionário disponíveis na pasta de dados.
  4. Leia o README da turma para as orientações dos trabalhos.
